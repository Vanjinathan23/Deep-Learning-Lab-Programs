# Deep Learning for Sustainability Lab

This repository contains the programs and implementations covered in the Deep Learning for Sustainability Laboratory manual.

## Contents

The programs cover topics including:

- Classification and Confusion Matrix
- Regression
- K-Nearest Neighbors
- Logistic Regression
- Naive Bayes
- Decision Trees
- Random Forest
- Support Vector Machine
- Gradient Descent
- Image Segmentation
- Neural Network Analysis

## Requirements

Install the required Python libraries before running the programs:

pip install -r requirements.txt
